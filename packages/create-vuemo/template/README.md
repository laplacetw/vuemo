# My Vuemo blog

```sh
pnpm install
pnpm dev                  # start the dev server
pnpm new my-first-post    # create posts/my-first-post.md
pnpm build                # build to .vitepress/dist
```

Posts live in `posts/` and static files in `public/`. All settings (site info, theme, comments, AI summary) live in `.vitepress/config.ts`; `.vitepress/theme/index.ts` is boilerplate you don't need to edit.
